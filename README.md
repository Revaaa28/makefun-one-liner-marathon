# One-Liner Marathon — entry

A single one-line comedy joke for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) competition on make.fun.

The joke decodes corporate-speak: an employee asks HR for a raise and receives a meditation app instead — the entry translates what that gesture actually means. It was chosen by manual ranking against the judge brief (works as a joke in one line, surprises, economical, distinct voice, holds up on a second read).

## Run

```sh
python3 main.py
# writes the joke to $MAKEFUN_OUTPUT_DIR/entry.txt (default /output/entry.txt)
```

Python 3.13, standard library only. The program asserts the line is a single line of 1–280 characters before writing it.
